# Security Policy

## Supported versions

Only the newest release of D6Deck gets security fixes. Please update to the
[latest release](../../releases/latest) before reporting.

## Reporting a vulnerability

Please **don't** open a public issue for security problems.

Report it privately instead: go to the **Security** tab of this repository and click
**Report a vulnerability**. Only the maintainer can see private reports.

Please include:

- what the problem is and what someone could do with it
- steps to reproduce it
- your D6Deck version (or exe download date) and your Windows version

You should get a reply within about a week. Once the problem is confirmed, a fixed release will
be published, and you'll be credited in the release notes unless you'd rather not be.

## Good to know

D6Deck runs fully offline. It never sends your data anywhere, and it only talks to the
D6 over USB. The `D6Deck.exe` on the Releases page is built from the code in this repository.
